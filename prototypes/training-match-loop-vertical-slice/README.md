# Training Match Loop Vertical Slice

## Hypothesis
Can a first-time player complete Training Day → Match Day → Post-Match Return in under 5 minutes without guidance, and understand that a training choice affected match feedback and the next growth decision?

## How to Run
1. Open the project in Godot 4.6.
2. Run `res://prototypes/training-match-loop-vertical-slice/vertical_slice_main.tscn`.
3. Complete the flow: Home → Team / Training → Match Center → Match Result → Home.
