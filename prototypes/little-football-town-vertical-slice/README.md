# Little Football Town Vertical Slice

## Hypothesis
Can a player complete one clear training-to-match-to-feedback loop in under 5 minutes without guidance?

## How to Run
1. Open the project in Godot 4.6.
2. Run `res://prototypes/little-football-town-vertical-slice/vertical_slice_main.tscn`.
3. Use the home, team, and match screens to play through one training-to-match-to-feedback loop.
