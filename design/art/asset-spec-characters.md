## 通用角色规则 (STYLE_GUIDE §5)

| 参数 | 值 |
|------|-----|
| 像素尺寸 | 32×48 px (含头顶留白) |
| 头身比 | 头 12px / 身体 24px / 腿 12px (运动比例) |
| 三要素 | 1 剪影特征 + 1 颜色强调 + 1 个人配件 |

## 动画帧数

| 动画 | 帧数 | 说明 |
|------|------|------|
| 待机 (Idle) | 2 帧 | 呼吸微动 |
| 走路 (Walk) | 4 帧 | 4 帧循环 |
| 跑动 (Run) | 6 帧 | 6 帧快循环 |

比赛自动跑动: 8 方向简化 (上/下/左/右 + 四斜向)

## 角色类型

### 1. 前锋球员 (Forward) — MVP 首产

| 参数 | 值 |
|------|-----|
| 剪影特征 | 微前倾姿势 |
| 颜色强调 | 鞋带/发带 俱乐部红 `#B84A4A` |
| 个人配件 | 护腿板 |
| 色板 | 俱乐部红 + 奶油色球衣 + 石板灰短裤 |
| 必含动画 | 待机 2帧 + 走路 4帧 + 跑动 6帧 |

### 2. NPC 教练 (Coach)

| 参数 | 值 |
|------|-----|
| 剪影特征 | 较直立，微宽肩 |
| 颜色强调 | 战术板/写字板 |
| 个人配件 | 口哨、笔记本、秒表 |
| 色板 | 冷静蓝 `#5E7FA3` 外套 + 大地棕裤子 |
| 必含动画 | 待机 2帧 (持战术板) |

### 3. NPC 居民 (Resident)

| 参数 | 值 |
|------|-----|
| 剪影特征 | 宽下摆、围裙/包/帽子 |
| 颜色强调 | 围巾 小镇金 `#D6B35A` |
| 个人配件 | 围裙/购物袋/自行车 |

### 4. 对手球员 (Opponent)

| 参数 | 值 |
|------|-----|
| 剪影特征 | 略带棱角 (非反派) |
| 颜色强调 | 对方俱乐部色 (非红) |
| 注意 | 不得使用俱乐部红 `#B84A4A`，不与主队颜色混淆 |

## 精灵表组织

```
[角色]_[动画]_[方向].png
例: forward_run_down.png

单张 sprite sheet: [角色]_spritesheet.png
  8 行 (8 方向) × N 列 (帧数)
  每帧 32×48 px
```

## 禁止

- ❌ 1:1 头身 Q 版比例
- ❌ 开罗风格建筑剪影复制
- ❌ 矢量/光滑材质
- ❌ 超大头身夸张表情
