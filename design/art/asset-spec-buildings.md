## 通用建筑规则 (STYLE_GUIDE §5)

- 最小尺寸: 2×2 Tile (64×64 px 原始, 128×128 px 显示 @2x)
- 斜屋顶占 1/3 高度，正面门廊/遮阳篷占 2/3
- 升级表现: 草皮变整齐 → 墙面增加粉刷线条 → 屋顶瓦片加深 → 门前增加盆栽/长椅
- 道具密度: 关键建筑周围聚集细节簇；路径和过渡区域保持稀疏

## 升级视觉差异

| 等级 | 变化 |
|------|------|
| Lv.1 (基础) | 简单外形，泥土周围 |
| Lv.2 | 草皮整齐 + 墙面清爽 |
| Lv.3 | 屋顶加深 + 门廊装饰 |
| Lv.4+ | 盆栽/长椅/旗帜 + 门前细节簇 |
