> **Status**: In Design
> **Author**: nico + ux-designer
> **Last Updated**: 2026-05-18
> **Journey Phase(s)**: 比赛准备 → 比赛进行 → 赛后结算
> **Platform Target**: PC Keyboard/Mouse
> **Template**: UX Spec

## Purpose & Player Need

比赛表现 UI 让玩家"在场边观看自己的球队踢球"。它把比赛竞技系统（ADR-0006）的演算结果转化为一场有叙事感的观看体验。

它回答三个问题：**赛前我准备好了吗？比赛中正在发生什么？为什么赢了或输了？**

它不定义比赛如何演算、积分如何累积——这些由比赛竞技系统和联赛系统拥有——而是负责把关键事件、比分变化、球员表现和复盘原因以有节奏、可理解的方式呈现给玩家。

MVP 中，比赛呈现是**自动演算、自动播放、观看优先**的：玩家**不直接控制场上球员**，只在赛前、赛中暂停/中场等节点执行教练层操作，如战术调整、换人、暂停、快进、跳过或放弃比赛确认。

MVP 核心目标：玩家在经历一场完整比赛（赛前→上半场→中场→下半场→赛后）后，能回答"发生了什么、为什么会这样、我赛前哪些选择影响了结果"。

## Player Context on Arrival

| 到达场景 | 情绪状态 | 设计含义 |
|----------|----------|----------|
| 从 HUD 的比赛入口或日程项进入比赛流程 | 期待、专注——准备迎接关键事件 | 赛前界面建立仪式感：对手对比 + 阵容确认 |
| 赛中观看事件流 | 紧张、投入——比分变化牵动情绪 | 自动比赛呈现需节奏清晰，进球与关键转折需最高视觉权重 |
| 中场调整 | 策略思考——想扭转或巩固局面 | 调整界面快速可操作，不打断比赛叙事流 |
| 赛后查看结果 | 满足或遗憾——想知道为什么 | 复盘原因标签 + 球员表现让结果可理解 |

## Navigation Position

```
HUD / 日程视图 → 比赛流程入口 → 赛前 (Match Pre) → 赛中 (Match Live) → 赛后 (Match Result)
```

比赛表现 UI 由 HUD 中的比赛入口或日程视图进入，并在 Match Pre、Match Live、Match Result 三个阶段全屏接管主内容区。根据 `design/ux/hud.md`，进入比赛流程后常驻 HUD 隐藏，离开比赛流程后恢复。赛中阶段不可通过常规导航离开——必须警告确认。

## Entry & Exit Points

| 入口来源 | 触发方式 | 携带上下文 |
|----------|----------|------------|
| HUD 比赛入口 | 点击比赛入口；或在 `match_trigger_reached = true` 时点击高亮的下一场比赛状态/入口 | 对手 + 联赛上下文 |
| 日程视图 | 点击赛程项 | 选定比赛 |

| 出口目标 | 触发方式 | 备注 |
|----------|----------|------|
| 赛中 (开赛) | 赛前「开始比赛」按钮 | 阵容必须满足最低合法条件 |
| 下半场 | 中场「确认调整」按钮 | 调整后锁定 |
| 赛后 → HUD 所在主循环界面 | 赛后「返回」按钮 | 确认结果后不可回退到赛中 |
| 赛中强行离开 | ESC 或暂停态中的放弃操作（警告确认后） | **单向出口**——视为放弃比赛 |

## Layout Specification

### Information Hierarchy

**赛前 (Match Pre)**

| 层级 | 信息 | 说明 |
|------|------|------|
| **L1** | 对手名称 + 队徽 + 实力对比 + 赛事背景 | 比赛上下文——"这场比赛的 stakes" |
| **L2** | 我方阵型图 + 11人首发位置 + 战术选择 | 核心操作区——确认/调整阵容 |
| **L3** | 替补席 + 换人次数 | 辅助信息——赛前最后检查 |

**赛中 (Match Live)**

| 层级 | 信息 | 说明 |
|------|------|------|
| **L1** | 实时比分 + 比赛时间/阶段 | 比赛状态的最核心锚点 |
| **L2** | 关键事件时间线（进球>普通事件） | 比赛的叙事线——"正在发生什么" |
| **L3** | 控制按钮（暂停/战术/换人/快进/跳过） | 仅提供教练层介入；不提供直接控球员操作 |

**赛后 (Match Result)**

| 层级 | 信息 | 说明 |
|------|------|------|
| **L1** | 终场比分 + 胜负标签 | 结果——最直观的反馈 |
| **L2** | 比赛数据对比 + MVP 球员 | 复盘数据——"为什么会这样" |
| **L3** | 结算明细 + 联赛影响 | 结果对后续的影响 |

## States & Variants

| 状态 | 触发 | 变化 |
|------|------|------|
| **赛前 Default** | 正常进入赛前 | 如 Wireframe |
| **赛前阵容不合法** | 阵容不足 7 人或无守门员 | 「开始比赛」按钮禁用 + 红色提示「阵容不完整——至少需要 7 名球员和 1 名守门员」 |
| **赛前对手未定** | 联赛未生成对手 | VS 区显示「对手待定——等待联赛抽签」 |
| **赛中 Default** | 开赛后正常播放 | 比赛自动播放；事件按节奏逐条出现，球场区装饰动画运行 |
| **赛中暂停** | 玩家点击暂停 / ESC | 事件停止滚动，比分栏覆盖半透明遮罩，控制栏切换为 [▶ 继续] [▶▶ 跳过] |
| **中场调整** | 上半场时间到 | 覆盖层弹出（不可跳过），显示半场统计 + 换人界面 |
| **赛中进球** | 任一方进球 | 比分脉冲放大 120% 持续 0.5s，事件流顶部插入进球事件（金色高亮 2s），球场区 ⚽ 闪烁 |
| **赛中红牌** | 任一方红牌 | 事件流插入红牌事件（红色边框），球员标记 🟥 |
| **赛后胜利** | 终场比分我方 > 对方 | 「胜利!」标签金色大号 + 球员欢呼像素动画 |
| **赛后平局** | 终场比分相同 | 「平局」标签灰色 + 复盘标签中性描述 |
| **赛后失利** | 终场比分我方 < 对方 | 「失利」标签暗色，复盘标签倾向「哪里不足」 |
| **赛后零进球** | 我方进球 = 0 | MVP 区域显示守门员或后卫最高评分球员 |
| **赛后放弃比赛** | 赛中 ESC / 暂停态确认放弃 | 比分判负 0:3，赛后结算区显示「放弃比赛——无正常比赛奖励」，复盘标签显示「放弃比赛」 |
| **退出警告** | 赛中按 ESC | 弹出确认框「离开将视为放弃比赛。确定离开吗？」[继续比赛] [确认放弃] |
| **Loading** | 赛前/赛后数据加载中 | 骨架屏（VS 区灰色占位 + 阵容图灰色圆点 × 11） |

### Focus Management by Overlay

#### Pause Overlay
- 打开时，焦点进入覆盖层中的第一个可交互元素（默认：`[继续]`）。
- Tab / Shift+Tab 只在暂停覆盖层内部循环，不得落到后方比分栏、事件流或控制栏。
- `ESC` 关闭暂停覆盖层并恢复比赛；关闭后焦点返回触发暂停的控件（若由键盘触发，则返回暂停按钮）。
- 若暂停后进入其他二级确认层，则暂停层焦点冻结，直到上层确认关闭。

#### Halftime Overlay
- 中场覆盖层出现时，焦点默认落在第一个可操作调整项；若没有可调整项，则落在 `[确认调整 ▶]`。
- Tab 顺序：半场统计摘要（只读可跳过）→ 调整项 → `[◀ 放弃比赛]` → `[确认调整 ▶]`。
- 覆盖层开启期间，后方 Match Live 控件不可聚焦、不可响应快捷键。
- `ESC` 不直接关闭中场覆盖层；如允许返回，应先进入“放弃本次调整？”确认，而不是静默退出。

#### Forfeit Confirmation
- 从 Match Live 或 Halftime 触发“放弃比赛”时，焦点默认落在安全选项（如 `[继续比赛]` / `[取消]`），防止误确认。
- Tab 只在确认弹窗内循环。
- `ESC` 关闭确认弹窗并返回其来源覆盖层/界面。
- 确认放弃后，不返回来源界面，直接进入判负结算路径。

#### Skip Match Confirmation
- 触发“跳过比赛”时，焦点默认落在取消选项。
- Tab 只在跳过确认弹窗内循环，不得落到后方快进/暂停/战术按钮。
- `ESC` 关闭确认弹窗并返回 Match Live。
- 确认后，比赛进入 `Skip Simulating` 状态；在该状态完成前不接受新的导航输入。

## Acceptance Criteria

- [ ] 赛前 VS 对比区正确显示双方队徽、队名、综合实力对比和赛事背景
- [ ] 阵容不合法时（少于 7 人或无守门员），「开始比赛」按钮禁用并显示红色提示
- [ ] 拖拽阵型图中的球员可交换位置，阵型标记为「自定义」
- [ ] 赛中事件时间线实时更新，最新事件出现在顶部，进球事件金色高亮 2s
- [ ] 比分改动时比分数字脉冲放大 120%，持续 0.5s
- [ ] 中场休息覆盖层显示半场统计数据（控球率/射门/射正），玩家可在此执行换人
- [ ] 赛中按 ESC 弹出放弃确认框，二次确认后判负 0:3 并跳转赛后
- [ ] 快进按钮切换事件播放速度至 2×，再次点击恢复 1×
- [ ] 跳过按钮直接跳到终场结果，弹出确认提示
- [ ] 赛后显示终场比分 + 胜负标签 + 复盘原因标签 + 数据对比 + MVP 球员 + 已接入的结算项
- [ ] MVP 球员卡片可点击进入 Player Detail（携带 player_id）
- [ ] 赛后「返回」按钮回到 HUD 所在主循环界面，不可回退到赛中
- [ ] Tab 键可在所有可交互组件之间导航，ESC 返回上级
